# Editor.js

[Editor.js](https://github.com/vollack/editor.js) is an open-source, block-styled editor that
outputs clean JSON instead of heavy HTML markup. This is a [vollack](https://github.com/vollack)
fork of [codex-team/editor.js](https://github.com/codex-team/editor.js/).

Each Block (paragraph, heading, image, list, quote, etc.) is provided via a separate plugin,
making Editor.js extremely flexible. The JSON output is easy to sanitize, extend, and integrate
with your own logic — use it in Web, iOS, Android, AMP, Instant Articles, speech readers, AI
chatbots, and more.

## Features

- Modern, block-style UI out of the box
- Clean JSON output
- Well-designed, extensible API
- Various official and community Tools available
- Free and open source
